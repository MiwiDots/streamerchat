  - ApplyUpdate() no longer takes a URL from the frontend. It used to

    the ~16 MB exe could never finish on connections slower than

    pre-release suffixes, so 0.3.9-alpha == 0.3.9 (alpha users never
    got the stable build) and beta.1 -> beta.2 was never offered.
    Unparseable tags are never treated as newer.
  - Note: clients <= v0.5.2 still update via their old updater code;
    the hardening applies from the next update after v0.5.3.
  - Tests: version ordering, asset validation (host/repo/prefix
